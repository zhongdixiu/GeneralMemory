# `business_domains` 场景规范化与内部检索调整计划

## 1. 字段契约与调整范围

保留 `business_domains` 的字段名和字符串数组类型，将其定义为：**记忆适用的业务任务场景集合**。

- `email` 表示邮件处理，`disk` 表示云盘文件管理，`communication` 表示非邮件通信；允许自动新增“方案编写”等任务场景。
- 数组元素表示 OR；`NULL` 表示已确认没有业务场景限制，不表示未知或必须返回。
- 依据记忆内容及明确上下文赋值，不依据来源 Agent、提及的主题或对象赋值。
- 客户、项目、操作条件等细限制保留在完整正文中；本轮不新增替代该字段的 `applicability` 字段。
- 覆盖抽取、内部检索、治理一致性、存量迁移及必要的画像兼容。公开 Search API 和完整画像生成仍留在原计划中。

## 2. 租户场景目录与自动赋值

新增租户级场景目录，保存规范值、定义和别名。规范值继续存入记忆的 `business_domains`。

- 各租户拥有相同的三个初始场景定义；新增场景和别名仅在本租户复用。保留已有初始值，不更换为另一套编码。
- 抽取先形成自足事实及其任务场景，再根据目录定义复用规范值。已有定义确实无法覆盖时，自动创建简短、明确的新场景。
- 同义表达归一；任务子类型可以归入已有场景，但正文必须保留更细条件。“方案评审”等不同活动不能只因主题相同而归入“方案编写”。
- 已有定义不因单条新记忆而自动扩大；同名异义使用可区分的新规范名称。不能确定适用范围时沿用现有未解决处理，不写成 `NULL`。
- 写入和新增目录项采用租户级并发复核；模型调用在事务外进行，提交前检查目录是否变化，必要时重新匹配，避免并发创建重复场景。
- 新增模型调用计入现有任务预算；保存规范化决定供重试复用，并更新输入快照与提示版本处理。

## 3. 内部检索与治理

增加面向任务的内部检索入口：接受 `query`、现有可信主体参数、结果数量及模型依赖；不要求调用方填写 `business_domain` 或 `context`。现有显式范围查询保留为兼容入口。

**检索流程：**

- 复用现有向量模型，为场景定义建立可重建的语义索引；查询只匹配已有场景，不创建场景。
- 合并“相关场景及业务不受限记忆”的召回结果与“不按业务场景限制的语义召回”结果，避免错误场景识别成为唯一过滤入口。候选预算沿用现有机制，两个通道均保留候选位置。
- 一次候选判断调用同时检查任务相关性、场景适用性和正文细条件。明确不适用的排除；信息不足但相关的，保留条件返回。
- 同一要求发生冲突时，仅当 query 明确满足更具体条件，才优先使用具体要求；范围交叉或信息不足时不擅自确定优先级。通用记忆的持久状态不因此改变。
- 返回完整记忆和规范场景值。授权、主体、生命周期等确定性过滤继续由代码执行；模型不得引用候选外 ID。
- 模型失败或输入无法在预算内完整处理时明确报告，不静默改成标签精确匹配。记录候选来源、排除及优先选择原因用于验证。

**治理一致性：**

- 抽取、Add 判重和后台整理使用同一场景目录。
- 场景相同仅作为候选依据；合并、替代、争议判断继续核对实际条件和时间语义，不能把数组相等当作完整范围相等。
- 同义名称不再阻止候选比较；通用要求与局部例外不能自动合并或整体替代。
- 推断的场景必须由依据支持并经过规范化，不能未经判断直接复制第一条依据的标签。
- 保留现有项目隔离、明确纠正证据和争议恢复规则。

## 4. 存量迁移与兼容

通过新增迁移建立场景目录，保持已有记忆、证据和审计关系。

- 提供默认只生成报告的迁移工具，逐条输出旧值、建议规范值、判断依据和未解决原因；应用阶段使用已生成的映射。
- 先检查完整正文，必要时核对来源。完成同义归一和场景登记；需要改变原适用含义的异常记录单列处理，不自动扩大范围。
- 保留记忆 ID、正文、状态、来源、证据及原审计；新增范围规范化审计。应用前复核输入未变化，重复执行不产生重复变更。
- 无法确定的记录保留原值并报告；不能转换为 `NULL`。过渡期检索为这些记录保留语义召回路径。
- 画像场景值同步处理无歧义的名称归一；遇到唯一键碰撞时保留记录并报告，不自动覆盖画像。
- 范围表达转换不触发重新抽取、合并、争议恢复或推断重建。切换前处理完已开始的旧版本任务，避免冻结输入与新规则混用。
- 更新字段规范、运行说明及开发计划，说明兼容入口与新入口的使用方式。

## 5. 验证与验收

使用数据库回归和合成数据真实模型评估，分别检查赋值、召回与最终适用性。

- **赋值：** 来源不决定场景；无业务限制事实保持 `NULL`；数组 OR 语义正确；对象和项目不混入场景。
- **目录：** 同义表达复用；不同任务自动新增；子类型条件保留；租户隔离、并发创建和重试幂等通过。
- **检索：** 无标签 query、同义任务、多场景任务和模糊查询均有案例；相关记忆进入候选，明确不适用记忆被排除，条件不明时完整返回条件。
- **优先级：** 海外客户邮件采用具体语言要求；收件人未知时不提前覆盖；无关要求不随整条记忆被压掉。
- **治理与迁移：** 同义范围可比较，细条件不同不误合并；局部例外不使通用记忆失效；旧 ID、状态和证据保持；画像碰撞及无法迁移记录有明确报告。
- 运行相关回归、静态检查和迁移幂等检查。真实模型评估记录误归一、重复建域、漏召回、范围误用、错误覆盖及调用成本；固定验收案例逐项通过，不以少量样例宣称生产质量已达标。

实施以当前工作区为基础，只修改这条内部闭环及必要兼容代码，保留其他未提交工作。
