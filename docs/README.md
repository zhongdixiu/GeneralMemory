## 各个模块相关的源码切入点

以下是按代码边界整理的**开发切入点**。

| 方向 | 建议先读 | 常改代码 | 协作接口 |
| --- | --- | --- | --- |
| 接入与鉴权 | Add 说明、接口总览 | `api.py`、`api_schemas.py`、`auth.py`、`ingest.py` | 与抽取模块约定来源和任务字段 |
| 事实抽取与模型 | 模块开发指南的“抽取” | `worker.py`、`providers.py`、`extraction_input.py` | 与接入模块约定输入，与治理模块约定事实和证据 |
| 检索与画像 | Search/Profile 说明、画像维度说明 | `retrieval.py`、`profile.py`、`profile_config.py` | 与维护模块约定向量状态、依据有效性 |
| 治理与生命周期 | 治理运行说明、修改删除说明 | `consolidation.py`、`governance_state.py`、`lifecycle.py`、`governance_worker.py` | 与检索、画像模块共用状态和证据规则 |
| 数据与迁移 | 数据模型设计规范、迁移报告 | `models.py`、`migrations/`、`migration_tools/` | 表结构变更需同步所有读写模块 |

修改前先确认会改动的 `memory_item` 状态、`memory_evidence` 关系、`memory_task` 类型和 HTTP 响应；它们是跨模块契约。若实现与某份历史设计稿不同，以代码、迁移和当前测试为准，并更新对应交接说明。
